Trust Manager Également connu sous le nom de : Certificate Trust Distribution Fait partie de Cert-Manager Trust Manager est utilisé par Aurora pour gérer et distribuer de manière centralisée les ensembles de certificats d'autorité de certification (CA) de confiance dans les clusters et les charges de travail Kubernetes. Il permet une configuration de confiance cohérente pour les composants de plateforme et d'application en synchronisant les certificats CA dans des ressources natives Kubernetes. Trust Manager réduit la dérive de configuration, simplifie la gestion de la confiance des certificats et prend en charge les communications entre services sécurisées dans les environnements à confiance zéro et d'entreprise. Rôle dans l'architecture Acts as a cluster-level controller that reconciles trusted certificate sources into Kubernetes resources such as ConfigMaps and Secrets. Trust Manager integrates with cert-manager and other certificate authorities to ensure workloads have access to up-to-date trust bundles required for secure communication.
