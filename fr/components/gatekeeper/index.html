Gatekeeper Également connu sous le nom de : OPA Admission Controller Gatekeeper est utilisé dans Aurora comme contrôleur d'admission Kubernetes pour imposer des contrôles de politiques et de gouvernance lors de la création et de la mise à jour des ressources. Construit sur Open Policy Agent (OPA), Gatekeeper permet l'application des politiques sous forme de code pour la sécurité, la conformité et les garde-fous de la plateforme, garantissant que les ressources Kubernetes respectent les normes approuvées avant d'être admises dans le cluster. Cette approche réduit les risques opérationnels et favorise une application cohérente des exigences d'entreprise et réglementaires. Aperçu Catégorie : Security
Type : Core
Version : 3.12.0 Déploiement Déployé dans : management-clusters, workload-clusters
Modèle de déploiement : Helm

Rôle dans l'architecture Acts as the admission-time policy enforcement layer for Kubernetes, intercepting API requests and evaluating them against OPA-based constraint templates and policies before resources are persisted.
