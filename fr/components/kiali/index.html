Kiali Également connu sous le nom de : Service Mesh Observability Kiali est une console de gestion pour le maillage de services Istio qui fournit une visualisation en temps réel de la topologie du maillage, des métriques de santé et une validation de la configuration. Dans Aurora, Kiali permet aux opérateurs de plateforme et aux équipes d'application de comprendre les communications entre services, de valider les configurations Istio, de résoudre les problèmes de connectivité et de surveiller la santé des services dans le maillage. Il offre une carte topologique visuelle, une animation du trafic et un audit de la configuration pour soutenir les opérations quotidiennes. Aperçu Catégorie : Observability

Rôle dans l'architecture Provides a visual management console and observability layer for the Istio service mesh. Kiali queries the Istio control plane and Kubernetes API to build a real-time topology view and validate mesh configurations.
