Loki Également connu sous le nom de : Log Aggregation System Loki est utilisé par Aurora comme système centralisé d'agrégation et de stockage des journaux pour les journaux de plateforme et d'application générés dans les clusters Kubernetes. Conçu pour être rentable et étroitement intégré à Kubernetes, Loki indexe les métadonnées plutôt que le contenu complet des journaux, permettant une requête efficace et une corrélation des journaux avec les métriques et les traces. Loki prend en charge le dépannage opérationnel, les enquêtes de sécurité et les cas d'utilisation d'audit sur la plateforme Aurora. Aperçu Catégorie : Platform Observability

Rôle dans l'architecture Acts as the centralized log storage and query backend for Aurora. Loki receives logs from node- and workload-level agents and exposes a query API that integrates with visualization and alerting systems. It is optimized for Kubernetes environments by leveraging labels for log correlation rather than full-text indexing.
